# Политика безопасности

Не публикуйте описание уязвимости в открытом issue. Передайте минимальный воспроизводимый пример владельцу репозитория через приватный канал GitHub Security Advisories.

Особенно важны сообщения об обходе ограничений GitHub URL, path traversal при распаковке, сохранении или исполнении исходников, попадании token в логи и SSRF.

MVP анализирует только публичные репозитории, никогда не выполняет их код и удаляет временный архив после завершения или ошибки.
